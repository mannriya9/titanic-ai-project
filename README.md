# Iris Flower Classifier - AI Project
A beginner machine learning project that predicts the type of iris flower based on its measurements.

# What it does
- Loads the Iris dataset (150 flowers, 3 types)
- Trains a Random Forest AI model
- Predicts flower type with high accuracy

# Libraries Used
- NumPy
- Pandas
- Scikit-learn

# How to Run
```bash
python model.py
```

# Output
- Model Accuracy: 100%
- Predicts flower type: setosa / versicolor / virginica
